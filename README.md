# Hyderabad Personal Trip Tracker

A static, mobile-friendly personal expense tracker. It stores data in the browser's localStorage and needs no backend or database.

## Deploy on Vercel
1. Upload these files to a GitHub repository (the `index.html` must be at the repository root).
2. In Vercel, choose **Add New → Project**, import the repository, and deploy.
3. No build command or environment variables are required. Vercel will serve this as a static website.
4. Open the deployed URL in iPhone Safari → Share → Add to Home Screen.

## Important storage note
Expenses are stored only in the browser on the device that entered them. They do not sync across devices. Use **Backup data** to download a JSON backup and **Restore backup** to import it later. CSV export is for spreadsheets.
